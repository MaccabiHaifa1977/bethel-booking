# Bethel Hostel – אתר, הזמנות אונליין, PayPal וקבלות ממורנינג

## מה יש במערכת

**אתר לאורחים** בעברית, אנגלית וגרמנית. אנגלית בכתובת `/`, עברית ב-`/he` וגרמנית ב-`/de`.
- דף בית, חדרים ומחירים, גלריה, מיקום, תנאי הזמנה, מדיניות פרטיות והצהרת נגישות.
- תהליך הזמנה בארבעה שלבים: תאריכים ← חדרים ומיטות ← פרטי האורח ← תשלום ב-PayPal.
- האורח ממלא שם מלא ומגדר לכל מתארח (לפי כללי הבית). המערכת בודקת שמיטות במעונות הגברים והנשים מתאימות למגדר.
- החדרים נשמרים לאורח ל-20 דקות בזמן התשלום. אם לא שילם, הם משתחררים אוטומטית.
- הכתובות של האתר הישן (למשל `/accommodation`) מפנות לדפים החדשים, כדי לשמור על הדירוג בגוגל.

**קבלות:** אחרי כל תשלום ב-PayPal המערכת מפיקה קבלה במורנינג (חשבונית ירוקה), והקבלה נשלחת לאורח במייל.

**פאנל ניהול** בעברית, בכתובת `/admin`:
- לוח בקרה עם המגיעים והעוזבים היום, התפוסה, והיתרות לגבייה.
- לוח תפוסה לפי חדר ומיטה. לחיצה על משבצת ריקה פותחת הזמנה חדשה.
- ניהול הזמנות: הזמנה טלפונית, חסימת תאריכים, שינוי תאריכים, החלפת חדר, רישום תשלום במזומן, אשראי, העברה או ביט (עם קבלה), החזר ב-PayPal וביטול.
- חדרים ומחירים: סוגי חדרים, מחיר לפי מספר האורחים, יחידות (חדרים ומיטות) ותמונות.
- הגדרות האתר: כל הטקסטים בשלוש השפות, פרטי קשר, כללי הזמנה, תנאים וגלריה.

## הרצה במחשב

```
cd C:\Users\simon\bethel-booking
npm install
npm start
```

אחר כך נכנסים ל-http://localhost:3470 (האתר) ול-http://localhost:3470/admin (הניהול).
סיסמת הניהול המקומית כתובה בקובץ `.env`, בשורה `ADMIN_PASSWORD`.

במחשב המקומי מצב ההדגמה פעיל (`DEMO_MODE=true`). אפשר לסיים הזמנה עם "תשלום הדגמה" בלי כסף אמיתי.

בדיקות: `npm run check` בודק את התחביר של כל הקבצים, ו-`npm test` מריץ בדיקה מלאה של תהליך התשלום והקבלה.

## חיבור PayPal

1. נכנסים ל-developer.paypal.com עם חשבון ה-**Business** של העמותה.
2. בוחרים Apps & Credentials ואז Create App. עושים את זה פעם אחת ב-Sandbox לניסיון, ופעם אחת ב-Live.
3. מעתיקים את Client ID ואת Secret למשתנים `PAYPAL_CLIENT_ID` ו-`PAYPAL_CLIENT_SECRET`.
4. מגדירים `PAYPAL_ENV=sandbox` לניסיון, או `PAYPAL_ENV=live` לתשלומים אמיתיים.
5. בפאנל הניהול, בדף חיבורים, לוחצים על "בדיקת חיבור".

## חיבור מורנינג (חשבונית ירוקה)

1. צריך מסלול **Best** ומעלה (₪54 לחודש, עד 50 מסמכים בחודש). אם יש יותר מ-50 תשלומים בחודש, צריך את מסלול Extra (₪89 לחודש).
2. סוג העסק במורנינג צריך להיות **עמותה**. כך הקבלות יוצאות בלי מע"מ.
3. יוצרים מפתח API לפי המדריך של מורנינג (greeninvoice.co.il/help-center/api). מעתיקים את ה-Client ID ל-`MORNING_CLIENT_ID` ואת ה-Secret ל-`MORNING_CLIENT_SECRET`.
4. לניסיון יש סביבת sandbox עם משתמש ומפתחות נפרדים (פרטים ב-developers.morning.co). בה מגדירים `MORNING_ENV=sandbox`. לקבלות אמיתיות מגדירים `MORNING_ENV=production`.
5. **לא** להפעיל במורנינג את "חיבור ל-PayPal". אחרת כל תשלום יקבל שתי קבלות.

סוג המסמך נקבע בהגדרות האתר. ברירת המחדל היא **קבלה**, שמתאימה לעמותה שהיא מלכ"ר. אם לעמותה יש תיק עוסק במע"מ על פעילות האכסניה, בוחרים "חשבונית מס / קבלה". כדאי לאשר את זה מול רואה החשבון.

## מיילים (לא חובה)

הקבלה ממורנינג נשלחת לאורח בכל מקרה. כדי שהאורח יקבל גם מייל אישור מסודר, ושהאכסניה תקבל התראה על כל הזמנה:
1. נרשמים ל-resend.com (בחינם עד 3,000 מיילים בחודש).
2. מאמתים את הדומיין bethel-hostel.com. מוסיפים ב-DNS את הרשומות ש-Resend נותן.
3. מגדירים `RESEND_API_KEY` ו-`MAIL_FROM` (למשל `Bethel Hostel <booking@bethel-hostel.com>`).

## העלאה לאוויר ב-Railway

1. יוצרים פרויקט חדש ב-Railway ומוסיפים לו שירות **PostgreSQL**.
2. מוסיפים שירות מהקוד. הדרך הקבועה היא דרך GitHub: עושים push לריפו, ו-Railway מעלה גרסה חדשה אוטומטית.
3. ב-Variables של השירות מגדירים:
   `DATABASE_URL=${{Postgres.DATABASE_URL}}`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `PUBLIC_URL`, `NODE_ENV=production`, ואת המפתחות של PayPal ומורנינג.
   **לא** מגדירים שם `DEMO_MODE`.
4. גרסת Node נעולה על 22 בקובץ package.json.
5. בפעם הראשונה המערכת יוצרת בעצמה את הטבלאות ואת החדרים. אחרי זה נכנסים ל-`/admin`, לדף חיבורים, ולוחצים "העתקת התמונות" כדי להעתיק את התמונות מהאתר הישן.

## דומיין

אפשר לחבר את bethel-hostel.com ישירות לאתר החדש, במקום אתר הוורדפרס. אפשרות אחרת היא להתחיל עם תת-דומיין, למשל book.bethel-hostel.com. ב-Railway בוחרים Settings, אחר כך Networking, אחר כך Custom Domain, ומוסיפים את רשומת ה-CNAME ב-DNS.

- [ ] לבצע הזמנה אחת ב-PayPal Sandbox ובמורנינג Sandbox, ולוודא שהקבלה הגיעה.
- [ ] לעבור ל-`PAYPAL_ENV=live` ו-`MORNING_ENV=production`, ולוודא ש-`DEMO_MODE` מחוק.

## הנחות שדורשות אישור

- חדר 4 (8 מיטות) מוגדר כמעונות **לגברים**, וחדר 6 (6 מיטות) כמעונות **לנשים**.
- הסטודיו (חדר 9) מוגדר לעד 2 אורחים ב-₪400. חדר המשפחה (חדר 8, ממ"ד) מוגדר לעד 4 אורחים: ₪250 לאחד, ₪300 לשניים או שלושה, ₪400 לארבעה.
- חדר 2 מוזכר באתר הישן אבל לא מוגדר. אפשר להוסיף אותו בדף החדרים.
- ביטול עד 24 שעות לפני ההגעה מזכה בהחזר מלא. את ההחזר מבצעים בלחיצה בפאנל הניהול.
- באתר הישן המחיר נקרא "תרומה נדרשת". באתר החדש הוא מופיע כ"מחיר ללילה". תשלום על לינה הוא תשלום על שירות, ולכן יוצאת עליו קבלה רגילה ולא קבלה על תרומה לפי סעיף 46.
